# VoltStop – class-project prototype

VoltStop is a **fictional** battery-swap business for electric boda bodas in Nakuru, Kenya,
made for a student class presentation. No real payments, camera or location are used.

Plain static site (`index.html`, `styles.css`, `app.js`), hosted on GitHub Pages.
Scan `voltstop-qr.png` to open it on a phone. Demo state lives in localStorage; use "Reset demo" on the Account tab.
